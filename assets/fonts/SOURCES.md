# Bundled fonts

Static Regular (400) and SemiBold (600) instances generated for Orbit from
the official Google Fonts variable files below using fontTools 4.61.1.
All other axes remain at their original defaults. Family/style metadata is
normalized for consistent Qt rendering. No glyph designs were changed.
Each family remains distributed under its accompanying SIL Open Font License.

- Manrope[wght].ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
  License: manrope-OFL.txt
- NunitoSans[YTLC,opsz,wdth,wght].ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/nunitosans/NunitoSans%5BYTLC%2Copsz%2Cwdth%2Cwght%5D.ttf
  License: nunitosans-OFL.txt
- Inter[opsz,wght].ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
  License: inter-OFL.txt

Loaded privately by Orbit; no system font installation is performed.
The original variable fonts are not needed at runtime. These static instances
avoid font engines that render a variable font only at its minimum weight.
